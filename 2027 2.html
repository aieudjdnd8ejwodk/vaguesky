How to Entry

エントリー方法

エントリーは専用Bot「M!st」で行います。代表者が1人で申請してください。

  1. /apply を実行する

    大会開催サーバー（Discord に参加）の申請用チャンネルで入力して実行します。

    /apply

  2. 申請フォームに入力して送信

    「大会参加申請フォーム」が開きます。

    チーム名チームの名前
    あなたのマイクラIDサブ垢はカンマで区切る（例 MainID,SubID）
    相方のDiscord名@ は不要。ユーザー名を入力
    相方のマイクラIDサブ垢はカンマで区切る（例 PartnerMainID,PartnerSubID）

  3. ロールを確認して完了

    あなたと相方に「大会参加申請済」と「チーム名」のロールが自動で付きます。

エントリー方法（動画）約68秒

超重要：相方は「表示名」ではなく「ユーザー名」で

✕ 表示名（ニックネーム）

入れると相方が見つからず、エラーになります。

○ ユーザー名（固有ID）

プロフィールに表示されている、英数字・記号だけのIDを入力します。

相方のDiscord IDの入力ミスが多発しています。送信前にもう一度確認してください。

やり直すときは /cancel

二度申請はできません。間違えたら /cancel で取り消してから、最初から申請し直します。

書いたIDだけが試合で使える

フォームに記入したマイクラID（サブ垢を含む）以外のアカウントは、試合で使えません。

「相方が見つかりません」と出たら

代表者は先に受け付けられます。相方のロールは、あとで運営が付与します。

Rules

大会ルール

エントリー前に必ず確認してください。くわしくは下の動画でも説明しています。

試合の流れ

  1. 試合開始

    自分の島とMidでアイテム集め

    戦闘開始までは攻撃禁止（準備時間）
  2. 残り 7:30

    戦闘開始

    ここから相手を攻撃できます
  3. 復活 5回

    Killされても5回まで生き返れる

    最大6回戦えます
  4. 残り 0:00

    Killが多いチームの勝ち

    同点なら延長戦「MIST式」

MIST式（延長戦）

試合を長引かせないためのルールです。

  1. お互い準備ができ次第、Midの中だけで試合開始
  2. Midから出ることは禁止
  3. どちらかが1Killを先取した時点で即試合終了
  4. Killを取られたチームの負け

Kickに関するルール

Kickとは、なんらかのエラーやバグで HIVE鯖を強制退出させられてしまうことです。パケットエラー・バグ・エラーによるKickは、すべて同じ扱いになります。

RULE 1

残り2分以上でKick

再試合を行います。最初からではなく、元の試合の残り時間だけを行います。

RULE 2

残り2分以下でKick

試合はそのまま続行。Kickされたチームの残った相方をKillすると、1Killにつき2pointです。

RULE 3

再試合でまたKick

同じチームが2度目のKick → ルール2の（）内を適用して続行。

もう片方のチームがKick → ルール1と同じく、試合をリメイク。

その他の決まり

  • Kill判定なら1point、ミス判定ならpointは入らない
  • CS再作成後5分以内にCSに参加できないと、失格になる場合がある
  • チームメンバーが2人ともKickされたら、その時点で強制敗北

MIST式の中でのKick

  • Kill判定 → その時点で試合終了
  • Miss判定 → 試合続行
  • 準備中のKick → そのまま試合続行
